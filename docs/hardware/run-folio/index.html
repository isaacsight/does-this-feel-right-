III

The reading

読み · PLAIN REGISTER · WHERE THE DATA IS THIN, IT SAYS SO

◇ At about 10x depth this run supports confident calls across the targeted panel regions and a genome-wide sketch. It does not support clinical interpretation, which begins near 30x — one PromethION cell, or three MinION cells pooled.

Read length (N50 11.4 kb) shows the extraction preserved DNA integrity, the step where most first runs fail. The pore-decay curve is normal for a 72 h run. A wash-and-reload could have recovered roughly 5 Gb more and was not attempted.

What we would do next, and what it would cost, is on the last page.

No "may indicate". If a sentence cannot point at a row of the ledger, it is not in the reading.

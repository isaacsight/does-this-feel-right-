# bench — the quantitative-hallucination benchmark

**The model proposes** an answer to a quantitative question: a `ModelAnswer`
`{task_id, value|null, unit, rationale, model_lineage, prompt_hash}`. A `Task` is
a `source_text` plus a `question` whose answer the text determines exactly
(`ground_truth {value, unit, tolerance}`), the plausible wrong numbers a model
might pick (`distractors`), and a `recompute_spec` saying how deterministic code
derives the answer from the source. `task_id` is the content hash of the task;
the shipped `taskset_v1` (`quant-hallucination` 1.0.0, 60 tasks: 20 invoice,
15 table, 15 arithmetic, 10 pdf_text) is generated by a seeded LCG and has one
`taskset_hash`.

**Deterministic scoring disposes.** `score` is pure: `abstained` (no value),
then `wrong_unit`, then `correct` if the decimal delta is within tolerance,
else `hallucinated`. `score_with_substrate` adds what `default_recompute` would
have produced from the source text and whether it would have `caught` the
model's wrong number (model wrong and recompute right). `run_benchmark` scores
every task, rolls up per domain, sorts by `task_id`, and seals the scores in a
`bench.score` envelope (`quant-bench@0.1.0`, inputs `{taskset_hash, responder,
scores}`) so a reported hallucination rate has a replay key.

**Nobody signs.** This wedge has no material gate and no audit sequence: the
sealed envelope is the artefact, and its `request_hash` is what a paper quotes.
Reference responders bracket the space: `OracleResponder` (always right),
`NullResponder` (always abstains), `DistractorResponder(seed, rate)` (picks a
distractor per task from a hash of seed and task id). `CallableResponder`
adapts any function so a real model can be measured without a provider
dependency.

## Quick start (Python)

```python
from provsubstrate.bench import (CallableResponder, DistractorResponder, OracleResponder, report_markdown,
                                 run_benchmark, score, score_with_substrate, taskset_v1)

ts = taskset_v1()
print(ts.name, ts.version, len(ts.tasks), ts.taskset_hash)

r = run_benchmark(ts, DistractorResponder(seed=7, rate=0.5), data_as_of="2026-08-17T00:00:00.000Z")
print(r.request_hash, r.hallucination_rate, r.caught_rate)
print(report_markdown(r))

# One task, one answer, by hand.
task = ts.tasks[0]
ans = OracleResponder().answer(task)
print(score(task, ans).to_json(), score_with_substrate(task, ans).to_json())

    return None
mine = CallableResponder(my_model, [{"model": "local-27b", "version": "2026-08"}], "a" * 64)
print(run_benchmark(ts, mine, data_as_of="2026-08-17T00:00:00.000Z").totals.to_json())
```

## Command line

```bash
provsub bench taskset --hash                          # 0c62ff6896a8...
provsub bench taskset --dump taskset.json
provsub bench run --responder oracle                  # JSON report with per-domain counts and request_hash
provsub bench run --responder distractor:7 --rate 0.5 --markdown
provsub bench run --responder null --results --out report.json
provsub bench score task.json answer.json
```

`--data-as-of` defaults to `2026-08-17T00:00:00.000Z` (the academic v1
constant), never a clock; pass another to bind another snapshot. MCP tools:
`bench_score`, `bench_run`, `bench_taskset`.

## Conformance kinds (academic v1)

| kind | case ids |
|---|---|
| `bench_taskset_hash` | v1 |
| `bench_score` | correct_exact, hallucinated_previous_total, abstained, wrong_unit, line_amount_off_by_unit_price, mean_within_tolerance, mean_just_outside, sum_off_by_one, math_off_by_one, pdf_half_year_only, substrate_abstains_on_unparsable |
| `bench_report_hash` | oracle, null, distractor_seed_7, distractor_seed_7_always |

`bench_report_hash` pins the full run's envelope hash and counts for the
reference responders; a port whose generator, scoring, or canonicalization
drifts fails it. See `src/provsubstrate/bench/conformance.py`.

## Audit-action sequence

None. A run seals its scores in one `bench.score` envelope; there is no gate and
no approval. Quote `taskset_hash` and `request_hash` when reporting a rate.

## Report header (what a paper quotes)

```
taskset_hash: {sha256}   responder: {model}@{version} prompt {prompt_hash[:12]}
engine: quant-bench@0.1.0   data_as_of {T}   request_hash: {sha256}
```

`caught_rate` is `caught / (hallucinated + wrong_unit)`: the fraction of wrong
numbers the substrate would have replaced with a recomputed one.

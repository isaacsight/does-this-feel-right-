# Shot list — THE EXPLANATION ARRIVES SECOND

Every narration beat maps to one visual action. **Information** and
**punchline** are both required; a row with an empty punchline gets rewritten,
not shipped. `kind` drives the shot-mix budget in EDITORIAL.md §4.

`lit` literal · `obj` object behaviour · `phys` cartoon physics ·
`anch` the heart anchor · `off` detective office · `fl` flourish

Frame count target: **~52**, average hold 5.2s, floor 1.8s, **ceiling 8.0s**
(the last film shipped four cuts over the ceiling — enforce it this time).

## Frames that must be generated and reviewed as a set

- **i08 / i09 / i10** — the anchor. Any drift in the heart's size, shape or
  position kills the film's central idea. Generate together, review together,
  reshoot together.
- **i36 / i37 / i38 / i39** — the 1962 sequence. The seated figure must be
  *identical* across conditions; that identity is the whole argument.
- **i20 / i33 / i35 / i52** — the office at establish, peak, reset and callback.
  Same room, same furniture, same camera height.

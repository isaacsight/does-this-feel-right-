### Style plate — accepted, with a caveat worth knowing

The plate came back **with the protagonist in it** despite the prompt saying
*"Completely empty of people. Nobody in frame."* Cause: reference 1 was a
character sheet, and passing a character reference **inserts that character**
regardless of the text. The instruction lost to the image.

Accepted anyway, because everything else landed: charcoal walls, a warm beige
pool of light, cream folders and boxes, the half-built stage set braced with
visible timber, and exactly one tomato-red object — which came back as **the
red mug**, the continuity prop from the last film. It doubles as the Act III
establishing frame (`m16`).

**Rule this creates:** for a pure environment plate, pass **no** character
reference. For every frame that should contain the protagonist, passing
reference 1 is doing real work.

## The four rules, applied

1. **Information AND a punchline.** Both columns filled, or the frame is
   rewritten rather than shipped.
2. **Red is evidence, correction and contamination — never decoration.** If it
   is red, the archive did it. The mug, the correction strip, the wrong-decade
   photograph's marker. One red element per frame, no more.
3. **Continuity.** ONE WORLD: the kitchen, the workshop, and a plain room for
   the evidence section. Recurring props: the red mug, cream folders, the
   half-built set.
4. **Situations, not symbols.** No diagrams. No floating brains. No glowing
   networks. Draw the person it is happening to.

**The anchor:** the kitchen. Same room, same camera position, same red mug
beside the sink. Curtains are the variable — blue in the remembered version,
absent in the true one, mid-repaint whenever the archive is working. Returns in
**I, IV, VI, IX**.

**Text:** zero lettering in any generated frame. Every label in the film —
ORIGINAL, CURRENT VERSION, ALSO A MEMORY, PROBABLY — is composited afterwards.
The archive is a room made of writing, which makes this the single largest
generation risk; scene text never names a readable object.

## Frames that must be generated and reviewed as a set

Reference #3 (previous approved frame) applies within each group.

- **m01 / m04 / m44 / m59** — the kitchen anchor. Same room, same camera, same
  red mug. If the room drifts, the film's spine breaks. Generate together,
  review together, reshoot together.
- **m16 / m43 / m47 / m58** — the workshop at reveal, peak, reset and coda.
  Same room, same shelving, same camera height.
- **m25 / m26** — the 1974 conditions. The questioner must be **identical**;
  only posture differs. That identity is the entire argument.
- **m48–m53** — the evidence section. One plain visual language, held
  deliberately flat, no variation in style between them.
- **m45 / m46** — the peak. Same frame, one beat apart. Must match exactly.
